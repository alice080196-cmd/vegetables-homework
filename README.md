# Vegetables

蔬菜主題網頁排版練習，以 HTML 與 CSS 呈現課堂設計的頁首、導覽列、主視覺、雙欄內容及頁尾。

## 內容

- 三張蔬菜圖片搭配名稱、介紹與料理提示。
- Contact 區包含品牌介紹與聯絡資訊。
- 導覽列可跳至對應的內容區域。
- 小尺寸螢幕採上下排列。

## 檔案結構

- `index.html`：網頁結構與文字。
- `css/style.css`：配色、字型、間距與響應式排版。
- `img/`：網頁照片與圖示。
- `fonts/`：Noto Sans 字型與授權文件。

## 設計設定

- 主要色：`#778A50`
- 頁面背景：`#EDF2C5`
- 文字色：`#7D7D7D`
- 內容背景：`#F7FBDA`
- 字型：Noto Sans

## 預覽

保留各資料夾結構，使用瀏覽器開啟 `index.html`。

登入與加入會員按鈕為版型示意，聯絡資訊為示例。
